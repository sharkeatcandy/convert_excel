# Excel 資料轉錄工具

純前端 Excel 轉錄網頁。檔案只在瀏覽器本機處理，不會上傳。網頁提供四種轉錄機制，下載檔名包含日期與分鐘。

## 使用方式

直接開啟 `index.html`，選擇上方分頁，再依序選擇來源資料與空白範本。

## 欄位規則

- C → C
- S + T − AE → L
- V → M
- W + AN → N
- Z → V
- AD → S
- B 的西元年月拆分為 J（民國年）與 K（月）

## 案件轉錄

- 每個案件先產生一筆「冠新」列，再接續廠商列
- C2 → B、H10 → C、H3 → D、D3 → E、L4 → F
- C17 → G、H5 → T（僅冠新列）
- 冠新列：H=`冠新`、I=`004銷貨收入`、K=`銀行存款`、L=`應收帳款`
- 廠商列：I=`004銷貨成本`、K=`應付帳款`、L=`銀行存款`
- 從第 28 列開始，每隔兩列動態讀取有效廠商：B → H、D → U
- C28、C30 及後續廠商列：擷取兩個英文字母開頭、後接數字的發票號碼 → P；單獨擷取民國日期字串 → O（月、日可為一或兩位數，例如 `115.7.29`、`115.07.09`，保留原格式），未找到時留空

## 舊版案件轉錄（.xls）

- 每個案件先產生一筆「冠新」列，再接續廠商列
- C2 → B、H10 → C、H3 → D、C5 → E、C4 → F
- C5 第二個底線後的十位數字 → G、H5 → T（僅冠新列）
- 冠新列：H=`冠新`、I=`004銷貨收入`、K=`銀行存款`、L=`應收帳款`
- 廠商列：I=`004銷貨成本`、K=`應付帳款`、L=`銀行存款`
- 從第 24 列開始動態讀取有效廠商：B → H、F 中的兩碼英文加八碼數字 → P、D → U
- 不符合字串規則的欄位會略過，並在網頁列出欄位和值

## 支出單轉錄

- A2 → D3
- B → C，並依明細筆數合併 C7 起的儲存格
- C + 空格 + D → D
- E → E、F → M
- B7 起填入 1、2、3…流水號
- 每筆明細的 G、H 維持逐列公式，H13 固定為 `SUM(H2:H12)`
- 範本最多支援 6 筆明細
